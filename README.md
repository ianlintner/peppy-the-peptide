# Peppy the Peptide

Comic-first, sourced lessons about peptides and molecular signaling. **Public MVP under construction**; see [PLAN.md](PLAN.md) for the approved course scope, quality gates, costs and deployment plan.

Software is MIT licensed. Peppy mascot art and derivative visual assets are excluded from the software license and reserved by their rights holder. This is educational satire, not medical advice or a treatment recommendation.

The first three-panel local prototype is being migrated into this repository. No deployed URL is claimed yet. Image generation occurs offline with a private fal credential; the public site never requests a model API.
