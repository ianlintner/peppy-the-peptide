# Artwork production record

The original Peppy reference was supplied by Ian Lintner. The selected course illustrations were generated using fal `google/nano-banana-2.1/edit` with the original and an approved classroom image as references, 1K output, 4:3 aspect ratio, one output per request, and editable dialogue kept outside the pixels. Peppy's fixed traits: seven linked colored spheres including a sky-blue winking head, white lab coat and gloves, and red sneakers.

- Foundation: three selected from four outputs. The first sequence comparison changed bead *composition* instead of only the order; a targeted correction made the same colors appear in two orders.
- Signal cast: two selected from two outputs. The two-envelope art is symbolic; a doorway and motion lines do not describe actual hormone entry or transport direction.
- Endogenous GLP-1: two selected from two outputs. The green envelope and receptor are symbols, not structures.
- Hormone ≠ medicine: two selected from three outputs. The first comparison placed the receptor closer to one envelope and was rejected; a targeted edit centered the fixed receptor between both.

**Nine selected panels from eleven outputs** overall. The six new panels used seven outputs; fal's published representative 1K/two-reference rate is around $0.044 per output before thinking-token variation, so this is an estimate rather than a statement of actual billed spend. The current production key cannot read fal's Admin usage API (HTTP 403). The private prompt/QA manifest stays outside Git in `.art-drafts/`, and the key is never in public source or client code. New lessons get a storyboard and exact controlled variable before any paid call. One initial generation plus at most one targeted correction per panel; otherwise substitute a deterministic diagram or defer. See [PLAN.md](PLAN.md).

Only optimized selected WebP files and the user-supplied source image are published. Code is MIT; art is excluded and reserved subject to applicable rights. AI-generated imagery can have limits on copyright protection.
